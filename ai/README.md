# AI Subsystem

Owners: Om (AI-1), Advait (AI-2)

The AI subsystem is optional and accelerates authoring by converting source PDFs into editable draft Course JSON.

Om owns document extraction/preprocessing.
Advait owns model generation/provider abstraction/output validation.

The rest of the product must work if this entire subsystem is disabled.

See `docs/AI.md` and `docs/COURSE_SCHEMA.md`.
