# Enthral LMS Validation

Web research or SCORM conformance alone cannot prove final compatibility. Generated packages must be tested in the actual target LMS environment.

## Record before integration testing

- confirmed supported SCORM target/version
- upload/import process
- test learner account/access
- completion rules expected by the LMS
- score/pass rules expected by the project

## Validation checklist

- package imports successfully
- launch file opens
- navigation works
- learner can complete required content
- score is reported correctly
- completion is reported correctly
- success/pass-fail is correct if used
- closing and reopening preserves agreed progress
- resume opens at expected location/state

Document LMS-specific quirks in this file as they are discovered.
